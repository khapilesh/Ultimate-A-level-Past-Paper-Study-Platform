# Temporary book-layout prototype

This is an isolated concept preview for an alternate IAL Mastery layout. It does not change the main app shell, CSS, or application routes.

Open `/prototype/flipbook/` in a static server from the repository root. The prototype loads the existing syllabus notes, walkthroughs, and original exam-style question banks so the bookshelf and page-turning interactions can be judged with real topics. The content is still authored by the main app; this folder changes only its temporary presentation.

If the design is rejected, delete this folder. If it is approved, the main app can be redesigned deliberately in a separate implementation step.
